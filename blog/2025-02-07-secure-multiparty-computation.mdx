# Secure Multiparty Computation: Real-World Implementations

> How to build privacy-preserving applications using modern MPC frameworks.

## 1. MPC Fundamentals

### 1.1 Core Concepts
- **Garbled Circuits**: Two-party computation using encrypted truth tables
- **Secret Sharing**: Data split into shares requiring threshold reconstruction
- **Oblivious Transfer**: Sender doesn't learn which item was received
- **Homomorphic Encryption**: Computation on encrypted data

### 1.2 Security Models
```
Semi-Honest (Honest-But-Curious)
├── Parties follow protocol but may analyze transcripts
└── Weaker but more efficient

Malicious
├── Parties may deviate from protocol
└── Requires additional zero-knowledge proofs
```

### 3.2 Implementation with OpenMined PSI
```python
from psi.protocol import PsiProtocol
from psi.encryption import ECEncryptor

# Initialize with curve parameters
curve = 'secp256k1'
encryptor = ECEncryptor(curve)

# Sample data
alice_items = ["alice@example.com", "bob@example.com"]
bob_items = ["bob@example.com", "charlie@example.com"]

# Create protocol instances
alice = PsiProtocol(encryptor, "alice")
bob = PsiProtocol(encryptor, "bob")

# Generate keys and process items
alice.setup()
bob.setup()

alice_hashes = alice.encrypt(alice_items)
bob_hashes = bob.encrypt(bob_items)

# Exchange hashes and compute intersection
alice_intersection = alice.compute_intersection(bob_hashes)
bob_intersection = bob.compute_intersection(alice_hashes)

assert alice_intersection == bob_intersection == {"bob@example.com"}
```

## 5. Privacy-Preserving Machine Learning

### 5.1 Secure Model Training
```python
# mpc/linear_regression.mpc
from util import mpc_math

class SecureLinearRegression:
    def __init__(self, n_features, learning_rate=0.01):
        self.weights = [sfloat(0) for _ in range(n_features)]
        self.bias = sfloat(0)
        self.lr = sfloat(learning_rate)
    
    def predict(self, X):
        # X is a list of secret-shared feature vectors
        return [self._predict_single(x) for x in X]
    
    def _predict_single(self, x):
        # Compute dot product + bias
        pred = self.bias
        for i in range(len(x)):
            pred += x[i] * self.weights[i]
        return pred
    
    def fit(self, X, y, n_epochs=10):
        n_samples = len(X)
        
        for _ in range(n_epochs):
            for i in range(n_samples):
                # Forward pass
                pred = self._predict_single(X[i])
                
                # Compute gradients
                error = pred - y[i]
                
                # Update weights
                for j in range(len(self.weights)):
                    grad = X[i][j] * error
                    self.weights[j] -= self.lr * grad / n_samples
                
                # Update bias
                self.bias -= self.lr * error / n_samples
```

```python
# Optimized secure comparison (less than)
def secure_less_than(a, b, bit_length=32):
    # XOR of a and b
    diff = a ^ b
    
    # Get the most significant bit (MSB) of the difference
    msb = 0
    for i in range(bit_length - 1, 0, -1):
        # Extract i-th bit
        bit = (diff >> i) & 1
        # OR with previous bits
        msb |= bit
    
    # If a < b, then (a - b) is negative (MSB = 1)
    return msb
```

### 7.1 MPC Wallet
```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract MPCWallet {
    address[] public owners;
    uint public threshold;
    
    struct Transaction {
        address to;
        uint value;
        bytes data;
        bool executed;
        uint confirmations;
        mapping(address => bool) isConfirmed;
    }
    
    Transaction[] public transactions;
    
    event TransactionProposed(uint txId, address proposer);
    event TransactionConfirmed(uint txId, address owner);
    event TransactionExecuted(uint txId, bool success);
    
    constructor(address[] memory _owners, uint _threshold) {
        require(_owners.length > 0, "No owners provided");
        require(_threshold > 0 && _threshold <= _owners.length, "Invalid threshold");
        
        owners = _owners;
        threshold = _threshold;
    }
    
    function proposeTransaction(
        address _to,
        uint _value,
        bytes calldata _data
    ) external onlyOwner returns (uint) {
        uint txId = transactions.length;
        Transaction storage transaction = transactions.push();
        transaction.to = _to;
        transaction.value = _value;
        transaction.data = _data;
        transaction.executed = false;
        transaction.confirmations = 0;
        
        // Auto-confirm by the proposer
        confirmTransaction(txId);
        
        emit TransactionProposed(txId, msg.sender);
        return txId;
    }
    
    function confirmTransaction(uint _txId) public onlyOwner {
        Transaction storage transaction = transactions[_txId];
        require(!transaction.isConfirmed[msg.sender], "Already confirmed");
        
        transaction.isConfirmed[msg.sender] = true;
        transaction.confirmations++;
        
        emit TransactionConfirmed(_txId, msg.sender);
        
        // Execute if threshold reached
        if (transaction.confirmations >= threshold && !transaction.executed) {
            executeTransaction(_txId);
        }
    }
    
    function executeTransaction(uint _txId) internal {
        Transaction storage transaction = transactions[_txId];
        require(!transaction.executed, "Already executed");
        
        (bool success, ) = transaction.to.call{value: transaction.value}(
            transaction.data
        );
        
        transaction.executed = success;
        emit TransactionExecuted(_txId, success);
    }
    
    modifier onlyOwner() {
        bool isOwner = false;
        for (uint i = 0; i < owners.length; i++) {
            if (owners[i] == msg.sender) {
                isOwner = true;
                break;
            }
        }
        require(isOwner, "Not an owner");
        _;
    }
}
```

```
Protocol            | Rounds  | Bandwidth (MB)  | Computation
--------------------|---------|-----------------|-------------
GMW (Semi-Honest)  | O(d)    | O(n·|C|)        | Low

BMR (Constant)      | O(1)    | O(n²·|C|)       | Medium
```

- **Vectorization**: Process multiple operations in parallel
- **Circuit Minimization**: Use arithmetic circuits efficiently
