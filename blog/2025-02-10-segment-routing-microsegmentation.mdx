# Segment Routing & Micro-Segmentation: Zero Trust Networks

> How to implement secure, scalable network segmentation with modern protocols.

## 1. Segment Routing (SRv6)

### 1.1 SRv6 Header Format
```
+-----------------+--------+--------+
| IPv6 Header    | SRH    | Payload |
| (Next=SRH)     |        |        |
+-----------------+--------+--------+

SRH (Segment Routing Header):
+-----------------+--------+--------+
| Next Header     | Hdr Ext Len |  Type=4  |
+-----------------+--------+--------+
| Segments Left   | Last Entry  |  Flags   |
+-----------------+--------+--------+
| Tag             | Segment List[0] (128-bit) |
+-----------------+---------------------------+
| ...             | ...                       |
+-----------------+---------------------------+
| Segment List[n]                           |
+-------------------------------------------+
```

### 1.2 Basic SRv6 Configuration (IOS XR)
```bash
# Enable SRv6
segment-routing
 srv6
  locator LOC1
   prefix 2001:db8::/64
   ! 64-bit SID allocation
   behavior usid
  !
 !
!

# Apply to interface
interface GigabitEthernet0/0/0/0
 ipv6 address 2001:db8:0:1::1/64
 srv6
  enable
  locator LOC1
 !
!
```

### 3.2 Policy Translation to SRv6 SIDs
```python
def policy_to_srv6_sid(policy):
    """Convert Zero Trust policy to SRv6 SID list"""
    srv6_sid = {
        'policy_id': policy['policy_id'],
        'segments': []
    }
    
    # Add source segment SID
    srv6_sid['segments'].append({
        'type': 'source',
        'segment': policy['source']['value'],
        'sid': get_sid_for_segment(policy['source']['value'])
    })
    
    # Add service function chain
    if 'service_chain' in policy:
        for service in policy['service_chain']:
            srv6_sid['segments'].append({
                'type': 'service',
                'name': service,
                'sid': get_sid_for_service(service)
            })
    
    # Add destination segment SID
    srv6_sid['segments'].append({
        'type': 'destination',
        'segment': policy['destination']['value'],
        'sid': get_sid_for_segment(policy['destination']['value'])
    })
    
    return srv6_sid
```

## 5. Network Observability

### 5.1 eBPF-based Flow Monitoring
```c
// eBPF program to monitor network flows
SEC("tracepoint/syscalls/sys_enter_connect")
int trace_connect(struct trace_event_raw_sys_enter *ctx)
{
    struct sockaddr_in *addr = (struct sockaddr_in *)ctx->args[1];
    __u16 port = 0;
    
    if (addr != NULL) {
        port = bpf_ntohs(addr->sin_port);
        
        // Log connection attempts to sensitive ports
        if (port == 22 || port == 3389 || port == 3306) {
            bpf_printk("Connection attempt to port %d\n", port);
            
            // Enforce policy
            if (!is_allowed_connection(ctx)) {
                bpf_override_return(ctx, -EPERM);
                return 0;
            }
        }
    }
    return 0;
}
```

## 7. Security Policy Automation

### 7.1 Policy as Code (Rego)
```rego
package microsegmentation

import input.connection

# Default deny all traffic
default allow = false

# Allow web to app tier on HTTP/HTTPS
allow {
    connection.src.workload == "web"
    connection.dst.workload == "app"
    connection.dst.port in {"80", "443", "8080"}
    connection.protocol == "tcp"
}

# Allow app to database on MySQL/Postgres
allow {
    connection.src.workload == "app"
    connection.dst.workload == "database"
    connection.dst.port in {"3306", "5432"}
    connection.protocol == "tcp"
    time.clock(time.now_ns())["hour"] < 22
    time.clock(time.now_ns())["hour"] >= 8
}

# Log all denied connections
violation[{"msg": msg}] {
    not allow
    msg := sprintf("Connection denied: %v -> %v:%v/%v", 
        [connection.src.workload, 
         connection.dst.workload, 
         connection.dst.port, 
         connection.protocol])
}
```
