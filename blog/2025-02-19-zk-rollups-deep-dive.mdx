## 2. Data Availability

### 2.1 On-Chain Data
- Transaction data in calldata
- Compressed batches
- Ethereum as data availability layer

### 2.2 Validity Proofs
- zk-SNARKs/STARKs
- Recursive proofs
- Aggregated verification

## 3. Performance

### 3.1 Throughput
- 2,000+ TPS (vs 15 ETH base)
- Sub-second finality
- Batch compression

### 3.2 Costs
- ~$0.01 per transaction
- Fixed verification cost
- Data compression savings

## 4. Security Model

### 4.1 Trust Assumptions
- Cryptographic security
- No need for fraud proofs
- Data availability checks

### 4.2 Withdrawals
- 7-day challenge period
- Mass exit mechanism
- Emergency shutdown
