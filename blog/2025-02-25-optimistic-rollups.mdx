# Optimistic Rollups Explained

## 1. Core Architecture

### 1.1 State Commitments
```solidity
contract Rollup {
    struct StateUpdate {
        bytes32 stateRoot;
        uint256 batchIndex;
        bytes32 previousStateRoot;
    }
    
    mapping(uint256 => StateUpdate) public stateUpdates;
    uint256 public challengePeriod = 7 days;
    
    function submitStateUpdate(StateUpdate calldata update) external {
        require(update.batchIndex == stateUpdates.length, "Invalid index");
        stateUpdates[update.batchIndex] = update;
    }
}
```
