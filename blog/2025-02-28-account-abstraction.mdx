## 4. Bundlers

### 4.1 Operation Flow
1. Receive UserOperations from clients
2. Simulate validation
3. Bundle into single transaction
4. Submit to EntryPoint

## 5. EntryPoint

### 5.1 Core Functions
- `handleOps()` - Process batch of operations
- `simulateValidation()` - Dry run validation
- `getSenderAddress()` - Deploy counterfactual wallet

## 6. Security Considerations

### 6.1 Common Vulnerabilities
- Reentrancy in validation
- Gas griefing
- Signature replay
- Frontrunning

## 7. Implementation

### 7.1 Setup with ethers.js
```javascript
import { Wallet, providers } from 'ethers';
import { SimpleAccountFactory__factory } from '@account-abstraction/contracts';

const provider = new providers.JsonRpcProvider(RPC_URL);
const owner = new Wallet(PRIVATE_KEY, provider);

// Deploy wallet factory
const factory = await new SimpleAccountFactory__factory(owner).deploy(ENTRYPOINT_ADDRESS);

// Get wallet address
const walletAddress = await factory.getAddress(owner.address, 0);
```
