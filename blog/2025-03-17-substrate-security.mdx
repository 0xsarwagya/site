### 2. Origin Checks

```rust
// Secure origin verification
ensure_root(origin.clone())
    .or_else(|_| ensure_signed(origin))
    .map_err(|_| Error::<T>::Unauthorized)?;

// Specific origin check
ensure_signed(origin)?;
ensure_root(origin)?;
ensure_none(origin)?;
```

## Common Vulnerabilities

1. **Arithmetic Over/Underflows**
   ```rust
   // Use checked_* methods
   let new_balance = balance.checked_add(amount).ok_or(Error::Overflow)?;
   ```

2. **Replay Attacks**
   ```rust
   // Include nonce in transactions
   let nonce = frame_system::Pallet::<T>::account_nonce(&sender);
   ensure!(nonce == expected_nonce, Error::InvalidNonce);
   ```

3. **Storage Attacks**
   ```rust
   // Limit storage growth
   ensure!(items.len() < MAX_ITEMS, Error::TooManyItems);
   ```
