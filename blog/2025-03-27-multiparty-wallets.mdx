## 2. Smart Contract Wallets

### 2.1 Gnosis Safe
```solidity
// SPDX-License-Identifier: LGPL-3.0-only
pragma solidity ^0.8.0;

contract GnosisSafe {
    mapping(address => bool) public isOwner;
    uint256 public threshold;
    
    function execTransaction(
        address to,
        uint256 value,
        bytes calldata data,
        bytes[] calldata signatures
    ) external {
        require(signatures.length >= threshold, "Not enough signatures");
        
        bytes32 txHash = getTransactionHash(to, value, data);
        address lastOwner = address(0);
        
        for (uint256 i = 0; i < threshold; i++) {
            address recovered = recover(txHash, signatures[i]);
            require(isOwner[recovered], "Not an owner");
            require(recovered > lastOwner, "Signatures out of order");
            lastOwner = recovered;
        }
        
        (bool success, ) = to.call{value: value}(data);
        require(success, "Call failed");
    }
}
```

## 3. MPC Wallet Architecture

### 3.1 Key Generation
1. Each party generates secret share
2. Exchange nonces and commitments
3. Compute public key
4. Verify key shares

### 3.2 Signature Flow
1. Initiate signing session
2. Generate nonces locally
3. Exchange nonce commitments
4. Reveal nonces
5. Generate partial signatures
6. Combine signatures
